# ВетАтлас

Учебная платформа по ветеринарной дерматологии собак и кошек на русском языке.

## Программа

- Все 22 темы исходного Word-файла, 7 направлений, 132 раздела.
- 120 рисунков этапов диагностики и 22 полных диагностических алгоритма.
- 110 вопросов в тематических и смешанном тестах.
- 66 заданий: 22 игры с диагностическим маршрутом, 22 игры на сопоставление и 22 клинических случая с 66 дополнительными вопросами.
- Поиск, фильтры, избранное, заметки, печать статей, история тестов и практики.
- Личный кабинет: профиль/группа, защищённый вход, серверное сохранение прогресса и продолжение на других устройствах.
- Гостевой режим доступен без авторизации; гостевой прогресс переносится в кабинет по отдельной кнопке.
- Приложение и учебные иллюстрации доступны без соединения после первого успешного кеширования. Для входа и облачной синхронизации нужен интернет.

## Исходники

- `public/` — самостоятельная учебная часть: HTML, JS, CSS, данные, рисунки и исходный DOCX.
- `public/exercises.js` — все задания; правильные индексы вариантов от0 до3, карточки sequence хранятся в правильном учебном порядке.
- `public/practice.js` — игровые форматы и клинические случаи.
- `public/account.js` — интерфейс кабинета и синхронизация с контролем версий.
- `worker/api.mjs` — API, проверки авторизации и изоляция записей студентов.
- `migrations/0001_student_accounts.sql` — схема таблицы аккаунтов, без пользовательских данных.
- `scripts/build.mjs` — детерминированная сборка Worker с локальными статическими файлами.
- `.openai/hosting.json` — идентификатор существующего проекта Sites и логическая привязка D1.
- `dist/` — генерируемый артефакт публикации, не является исходником.

## Сборка и размещение полной версии

Нужен Node.js22.13 или новее. Для самой сборки npm-зависимости не требуются.

    npm run build

Результат: `dist/server/index.js`, `.openai/hosting.json`, метаданные Worker и SQL-миграции. Публикация существующего проекта выполняется через Sites с тем же project_id. Ресурс D1 привязан как DB; SQL-миграцию нужно применить перед первым использованием аккаунтов. Код не создаёт таблицы при обработке запросов.

Вход опубликованной версии принадлежит платформе Sites: `/signin-with-chatgpt` и `/signout-with-chatgpt`. Платформа добавляет доверенный стабильный идентификатор пользователя в заголовки запросов. Страница входа открывается обычной ссылкой верхнего уровня. Пароли в приложении не собираются и не хранятся. Не размещайте API за прокси, позволяющим посетителю подделывать эти заголовки. На другом хостинге нужно подключить собственную проверенную авторизацию и изменить адаптер идентификации, сохранив серверные проверки доступа.

Для обычного Cloudflare Worker настройте D1, примените SQL и замените пример database_id в сгенерированной конфигурации реальным ID вашего ресурса. Одного статического хостинга для серверного кабинета недостаточно.

## Статическая учебная копия

Кнопка «Скачать сайт» сохраняет автономную учебную часть. Для публикации этой копии загрузите содержимое архива на статический хостинг с HTTPS. Текст, схемы, игры, клинические задачи и гостевой прогресс работают без серверной БД. Серверный кабинет в статической копии требует отдельно размещённого API и авторизации.

Полный проект с серверной частью доступен по `downloads/vetatlas-server.zip` на опубликованном сайте. Этот архив содержит исходники и миграцию без данных студентов и секретов.

Для локального чтения статической копии:

    cd public
    python3 -m http.server 8080

Откройте http://localhost:8080. Навигация через # работает без перенаправлений. Все шрифты и иллюстрации локальны, CDN для работы учебной части не нужен.

## Данные и синхронизация

Гость сохраняет данные в браузере. После авторизации отдельная копия прогресса привязана к стабильному ID пользователя и хранится в D1. Все запросы сервер ограничивает текущим владельцем; чужой ID из тела запроса не принимается. Записи аккаунтов не выдаются в публичном каталоге.

Сохраняются отметки изучения, избранное, заметки, последние100 результатов тестов и200 попыток практики. Смена пользователя переключает отдельное хранилище, а текущая игровая попытка другого пользователя не переносится. Гостевые данные не объединяются с кабинетом без явного действия студента.

При параллельном изменении прогресса на двух устройствах сервер возвращает конфликт версии. Студент может загрузить облачную копию либо явно сохранить текущую. Экспорт создаёт резервную копию JSON; импорт заменяет текущий прогресс. Учебные результаты не являются защищённой аттестацией или официальной оценкой.

Не вводите персональные данные пациентов в заметки. Сайт не использует рекламу и стороннюю аналитику. Приватные API-ответы не кешируются; service worker сохраняет только публичную учебную часть и исключает API и пути входа/выхода.

## Учебная редактура

Материалы опираются на указанные ветеринарные источники. Они не заменяют осмотр и назначения ветеринарного врача. Перед включением в официальную учебную программу требуется предметная редактура преподавателем. Дозировки и индивидуальные назначения не приводятся.

Изображения — условные учебные иллюстрации. Источники рисунков и лицензия шрифта Manrope указаны в assets/credits.json и assets/Manrope-OFL.txt. Исходный Word-файл сохранён дословно в статьях и доступен в downloads/original.docx.

## Проверка

Проверены22 статьи,120 этапов,66 интерактивных заданий, регрессия тестов, реальные SQL-операции аккаунтов, изоляция пользователей, защита записей, конфликты синхронизации и статические ответы Worker. Проверки интерфейса выполняются через DOM-сценарии; визуальная проверка страниц и реального внешнего входа в браузере текущей среды недоступна.
