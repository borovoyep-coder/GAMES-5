# ВетАтлас

Самостоятельный учебный сайт по ветеринарной дерматологии на русском языке.

## Состав

- 22 темы из исходного Word-документа, 7 направлений.
- 132 учебных раздела: причины, признаки, диагностика, дифференциальные диагнозы, принципы ведения, профилактика.
- 110 вопросов с объяснениями, тематические тесты и смешанная выборка из 20 тем.
- 7 оригинальных векторных иллюстраций и 22 иллюстрированных диагностических алгоритма: 120 рисунков этапов, 22 полные схемы, интерпретация результатов и клинические развилки.
- Поиск, фильтры, избранное, личные заметки, печать статей, прогресс, экспорт и импорт результатов.
- Исходный DOCX сохранён в downloads/original.docx и дословно процитирован в каждой теме.

## Размещение

Приложение не требует сборки, сервера приложений, базы данных или API-ключей.

Для размещения исходного проекта загрузите **содержимое dist/** в корень любого статического хостинга с HTTPS. Если вы скачали архив через кнопку «Скачать сайт», index.html уже находится в корне архива — загрузите всё его содержимое на хостинг.

Подойдут GitHub Pages, Cloudflare Pages, Netlify и обычный хостинг с поддержкой статических HTML-файлов. Команда сборки не нужна. В исходном проекте каталог публикации — dist; в скачанном архиве — корень.

Навигация использует #, поэтому серверные перенаправления на index.html не требуются. Сайт работает в подкаталоге. Все шрифты и иллюстрации локальны, внешние CDN не используются.

Для проверки на своём компьютере из каталога с index.html:

    python3 -m http.server 8080

Откройте http://localhost:8080. Прямое открытие index.html также позволяет читать материалы, но возможности локального хранения могут зависеть от браузера; предпочтителен локальный сервер.

## Редактирование

- data.js — весь учебный контент в window.COURSE: заболевания, разделы, источники и тесты. Вопрос содержит options из 4 вариантов, answer — индекс верного варианта от 0 до 3.
- diagnostics.js — этапы диагностики для каждой темы, клиническая логика, источники и пути к рисункам.
- assets/diagnostics/ — отдельный рисунок каждого этапа и полная схема каждого алгоритма в SVG.
- app.js — маршруты, пошаговый просмотр диагностики, поиск, тестирование, локальное хранение.
- style.css — адаптивный дизайн, светлая палитра, версия для печати.
- assets/ — иллюстрации, шрифт Manrope и лицензия OFL, credits.json.
- index.html — оболочка сайта, метаданные, навигация.

При изменении контента синхронизируйте заявленные количества тем/вопросов в текстах, если программа меняется. В текущей версии каталог рассчитан на 22 темы.

## Данные студентов

Заметки, избранное, отметки об изучении и последние 100 результатов хранятся в localStorage браузера. Текущая попытка теста — в sessionStorage вкладки. Нет регистрации, преподавательской панели, общего журнала оценок или синхронизации между устройствами.

Прогресс можно экспортировать и импортировать JSON-файлом в разделе «Мой прогресс». Очистка браузера удаляет данные, если ранее не был выполнен экспорт. Не храните персональные данные пациентов в заметках.

## Учебная редактура

Материалы расширены по ветеринарным источникам; ссылки приведены в каждой теме. Профессиональная рецензия ветеринарным специалистом не заявляется. Перед использованием как официального учебного пособия нужна предметная редактура преподавателем.

Принципы ведения не заменяют индивидуальные назначения; дозировки не приводятся. Схематические рисунки не являются клиническими фотографиями. Главное изображение показывает условную учебную ситуацию. Manrope распространяется по SIL Open Font License 1.1 (assets/Manrope-OFL.txt).

## Проверка готовности

Выполнены проверки синтаксиса JavaScript, структуры 22 тем/110 вопросов, дословного переноса исходных абзацев, локальных ассетов и автоматические DOM-сценарии пошаговой диагностики всех 22 тем, навигации между этапами, поиска, фильтров, избранного, заметок, отметок об изучении, полного тематического и смешанного теста, результатов, прогресса и словаря. Отдельные рисунки и полные схемы проверены на корректность SVG; выбранные рисунки растеризованы для визуальной оценки. Визуальная проверка страниц в реальном браузере в текущей среде недоступна. Дизайн адаптирован для ширин 640, 820 и 1100 px; перед официальным запуском желательно проверить его на ваших устройствах.
